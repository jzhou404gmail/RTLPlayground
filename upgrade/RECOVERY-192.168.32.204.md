# 恢复 192.168.32.204（IG204 4+2 / PB-2131）

## 发生了什么

升级时给这台 IG204 用了 **Dual-I/O（默认）** 构建的镜像，但这台机器原来的闪存是
**1 MiB Macronix MX25L8005M**（`flash_size` 报 1 MB），这颗芯片必须用
`FLASH_NO_DIO=1` 构建。写进去的镜像在 `Detecting CPU` 之后取指失败，板子进入
约 10 ms 一次的复位循环：链路灯/PHY 还亮着，但网络和 Web 都不会起来，因此
**没法再通过网络升级**。

现在准备换回原厂 **4 MiB cFeon EN25QE32A** 也可以：单比特 fast read 对这两颗
芯片都安全，用同一份 `FLASH_NO_DIO=1` 镜像即可（只是编程器镜像要按芯片容量
填充）。

这不是 target 选错，也不是板子坏了；同一颗芯片用单比特 fast read 的镜像是可以
正常启动的（见 `doc/devices/STEAMEMO_IG204_V1.md` 与 README 里
`FLASH_NO_DIO=1` 的说明）。

## 需要做什么：用 SPI 编程器重刷

IG204 没有复位键，也没有网络恢复模式，只能用 SOP-8 夹子/编程器把闪存重新写一遍。

1. 断电，打开外壳；闪存是底面的 SOP-8 `U5`（1 MiB `MX25L8005M`；如果这台换过
   原厂 4 MiB `EN25QE32A`，以实际丝印为准）。
2. 夹上 SOP-8 夹子（Pin 1 红线对准芯片圆点），编程器选 **3.3 V**。
3. 先备份现有闪存（虽然已经是坏镜像，留个底）。
4. **整片擦除**（不要只擦前 512 KiB；4 MiB 芯片上 `0x80000` 起的旧内容可能被
   启动时的升级检查误认成待升级镜像）。
5. 写入（v0.1.1 镜像，`192.168.10.247` 保底地址）：
   - 4 MiB `EN25QE32A`：写 `upgrade/fw/v011/ig204-nodio-4MiB.bin`（512 KiB 镜像 +
     0xFF 填充到 4 MiB，写偏移 0）。这样 `0x80000` 之后的升级暂存区也是干净的
     0xFF，最省事。
   - 1 MiB `MX25L8005M`：写 `upgrade/fw/v011/ig204-nodio-1MiB.bin`（512 KiB +
     0xFF 填充到 1 MiB，偏移 0），或直接写 `upgrade/fw/v011/ig204-nodio.bin`
     （512 KiB，偏移 0）。
6. 回读校验，拔夹子，上电。

> 这三个文件都是 **`FLASH_NO_DIO=1`** 构建的。`output/STEAMEMO_IG204_V1/` 里
> `rtlplayground-v0.1.1-5911eda-dirty-STEAMEMO_IG204_V1.bin` 也是同一份 512 KiB
> no-DIO 镜像（sha256 `5b961f82…`），只是文件名看不出构建参数；如果要用它，
> 也必须先整片擦除再写偏移 0。
>
> 不要拿 `output/` 里更早的 DIO 构建去刷 IG204。4 MiB 填充镜像只给编程器用，
> **不要**通过网页升级上传（网页只收 512 KiB）。

## 重刷之后

- 镜像内嵌的出厂配置是 `ip dhcp`、**无密码**，所以机器会直接通过 DHCP 拿地址，
  网页默认端口是 **80**（旧配置里的 8000 已随配置区一起被覆盖）。
- 如果这个网段没有 DHCP 服务器，IG204 的保底地址是 **`192.168.10.247`/24**
  （网关 `192.168.10.1`），把电脑网卡设成 `192.168.10.x/24` 就能访问。
- 在路由器 DHCP 租约里按 MAC `06:05:07:7a:94:3d` 找它，或者扫 80 端口。
- 想恢复原来的 hostname/DNS/NTP/8000 端口，登录后把
  `upgrade/config/204.txt` 的内容写进启动配置（或直接网页里改），保存并重启。
- 以后给这台机器编译必须带：

  ```bash
  make MACHINE=STEAMEMO_IG204_V1 FLASH_NO_DIO=1
  ```

## 现场检查清单

- [ ] 芯片丝印确认（MX25L8005M / EN25QE32A）
- [ ] 编程器 3.3 V，Pin 1 方向
- [ ] 整片擦除（4 MiB 芯片尤其要擦到 `0x80000` 以后）
- [ ] 写入后回读校验
- [ ] 上电后 DHCP 租约出现 `06:05:07:7a:94:3d`
- [ ] `http://<新地址>/information.json` 直接返回 200（不需要密码）
- [ ] 版本为 `v0.1.1-5911eda-dirty`
